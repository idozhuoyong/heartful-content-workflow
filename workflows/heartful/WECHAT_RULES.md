# 小卓心享公众号规则

默认账号为“小卓心享”，不据此推断作者身份与读者画像。用户指定其它账号或要求时，在本次运行中记录覆盖。证据和叙事边界见 [领域规则](DOMAIN_RULES.md)。

## 选题与表达

默认一次一篇。用户已给主题时聚焦切口；没有主题时比较 3 个候选，说明具体读者处境、核心问题、内容增量、证据可得性和表达风险。选题不强制追热点，不沿用汽车热点的时效权重。

首版默认写给面对日常情绪与成长问题的普通成年读者；这是可覆盖的编辑假设，不是账号既有画像。目标读者或叙事方向存在关键分歧时先确认。

语气温暖、平等、克制，使用具体场景和自然短段落。避免居高临下、绝对判断、羞辱式激励、贩卖焦虑和空泛金句堆叠。标题准确呈现文章价值，不夸大效果或用疾病标签吸引点击。

篇幅由主题和用户需求决定；未指定时以正文约 1200 至 1600 个非空白字符作为初稿参考，标题、小节标题、图注与内部记录不计入。此范围是本项目首版编辑默认，不是用户已验收的账号标准，不为凑字重复观点。短随笔等文体可记录理由后采用更短篇幅。

文章结构随文体调整，不强制“痛点、故事、金句、升华”的套路。方法文章说明适用情境和可执行步骤，生活随笔保留观察细节，阅读文章区分原著观点与自己的理解。

## 图片与视觉

初稿可先交配图计划；完整图文交付包含独立封面和与内容需要相符的正文图片，不复制汽车文章图数。图片数量与位置在本次运行中确定，避免装饰堆积。

视觉以清晰、舒适、留白和可读性为目标。当前未确定颜色、字号、行距与平台主题，不冒称与汽车项目排版一致。实现 HTML 时须先建立唯一样式基线，本地预览与公众号导入件由同一渲染流程生成；中文标点与中英文、数字间距由渲染层确定性处理。平台实际预览另行核对。

## 审核与交付

逐项审核：主题聚焦、内容增量、真实叙事、事实出处、专业边界、非说教表达、标题、隐私、图片许可及中文排版。审核报告记录结论、问题、采用版本和未验证范围，不能以“有共鸣”代替事实核查。

交付提供正文、配图计划或实际素材、来源与主张记录、审核报告及交付清单。当前不要求尚未实现的 HTML 导出器作为文字稿交付前提；仅有文字或图片需求时明确称为文字稿交付，不能称为完整待发布图文包。

回复中的交付入口使用实际存在文件的完整绝对路径链接。保存草稿、正式发布和平台视觉验收分别汇报，按 [交接协议](../../docs/PORTABILITY_PROTOCOL.md) 记录外部操作。
