# 小卓心享内容工作流

`heartful-content-workflow` 是“小卓心享”的文件驱动内容生产项目，面向情绪疗愈、生活感悟、自我成长等主题，首次服务公众号。

内容从具体生活问题出发，提供理解、观察或可实践的方法。允许温暖的随笔，也允许有证据的知识解释、观点讨论、阅读思考和实践复盘；不以励志金句或固定的“鸡汤文”结构限制内容。

## 当前可用范围

目前提供可由具备文件读写能力的 Agent 手动执行的工作流文档，包括需求确认、选题、资料核实、写作、配图规划、审核与交付。尚未完成真实稿件试跑。

项目沿用 `car-content-workflow` 的组织方式：运行状态与内容落盘、领域和平台职责分离、交付与发布分开判断。两个项目独立维护，当前没有共享运行库或自动同步机制。

## 使用方式

在本目录打开 Agent，读取项目规范和工作流后，可下达：

> 执行小卓心享内容工作流，围绕“总觉得休息是一种浪费”写一篇公众号文章，以生活观察为主，完成后停在待审批阶段。

也可提供个人笔记、参考文章或主题，不必依赖当天热点。没有指定主题时，Agent 先给出候选切口，再按工作流判断是否需要用户确认；不能凭账号名称推断读者年龄、性别或作者经历。

运行时创建 `runs/<run_id>/`，将输入、来源、决策、稿件及审核结果保存在其中。中断后按 [交接协议](docs/PORTABILITY_PROTOCOL.md) 恢复。没有联网能力时可以写明确标注的个人观察或基于用户资料的文章，不能声称已核实外部事实。
